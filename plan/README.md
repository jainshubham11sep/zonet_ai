## How to Use This Folder

- One `.md` file per major feature or decision
- Update status as phases complete
- Use checkboxes `- [ ]` for tasks so progress is trackable
- Don't delete old plans — mark them `Status: Complete` or `Status: Abandoned`

---

## Plan Template

Copy this for new features:

```markdown
# Plan: [Feature Name]

**Status**: Planning / In Progress / Complete / Abandoned  
**Created**: YYYY-MM-DD  
**Last updated**: YYYY-MM-DD

---

## Overview
[What it is, why we're building it]

## Phase 1 — [Name]
- [ ] task
- [ ] task

## Phase 2 — [Name]
- [ ] task

## Notes / Decisions
[Key choices made and why]
```

---

## Naming Convention

`FEATURE-NAME-PLAN.md` — all caps, hyphens, descriptive.

Examples:
- `AUDIT-TOOL-PLAN.md`
- `BACKEND-SETUP-PLAN.md`
- `COMPETITOR-COMPARISON-PLAN.md`
